# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **Nexura Upload Limits Manager**, please do not open a public issue. Instead, report it directly to our security team via email at `security@nexurasecurity.com`.

We will acknowledge receipt of your vulnerability report within 24-48 hours and work on a fix immediately.
